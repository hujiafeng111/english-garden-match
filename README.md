# 英语花园消消乐（四六级版）

花园主题的英语单词消除游戏。进入页面可选四级或六级，消除后显示中文并朗读英文和中文；每通关一关收获一捧花，八种花束在第 1、3、5、8、12、18、25、40 关解锁。

目前是玩法原型：四级、六级各含六个样例单词，尚未完成真题频次核验，不应作为完整考试词库宣传。进度存储在本机浏览器或桌面 App，各设备和版本之间暂不自动同步。朗读依赖系统语音支持。

## 网页

运行 `node scripts/build.cjs`，将 `dist/` 内的文件发布到静态网站服务器。入口为 `index.html`。

本地预览：`npm run build` 后执行 `npm run serve`，访问 `http://127.0.0.1:4173`。

网页具备 PWA 安装和离线缓存功能。通过 HTTPS 或 localhost 首次完整访问后，支持该功能的浏览器可以安装到本机；首次成功缓存后，页面和花束可离线打开，朗读是否离线可用取决于系统语音。

## iPhone App

使用 iPhone 的 Safari 打开已部署的 HTTPS 网页，点击分享，选择「添加到主屏幕」。主屏幕图标打开游戏时以独立窗口运行，首次完整加载成功后可离线打开游戏页面。页面含有「安装到 iPhone」提示按钮。

这是 PWA 网页 App，不是 IPA 或 App Store 原生应用；原生 iOS 打包另需 Apple 开发者签名及 Xcode/macOS 构建环境。浏览器和主屏幕 App 的存储行为取决于 iOS 版本，清除网站数据会清除进度。

## 腾讯云发布

已有轻量服务器或 CVM：将 `dist/` 上传到 `/var/www/english-garden/`，根据服务器的实际配置启用 `deploy/nginx.conf`。该文件是配置模板，必须先替换域名并检查现有服务；需要服务器访问权限才能实际部署。安装到本机的网页功能要求 HTTPS（localhost 除外）。

COS：上传 `dist/` 内容并开启静态网站托管；新建存储桶需要可用的自定义域名，不能直接依靠默认 COS 域名展示 HTML。具体地区、备案和 HTTPS 配置需按账号资源核对。

GitHub 仓库附带 Pages 工作流，可在仓库设置中选用 GitHub Actions 作为 Pages 发布来源；腾讯云也可以使用同一份 `dist/` 文件。
