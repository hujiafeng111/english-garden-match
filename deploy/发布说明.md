## 交给部署 agent 的任务

将当前项目最新版本更新至上述现有站点。部署前读取服务器实际 Nginx 配置，确认监听 8000 端口的 server 块对应的 root 或 proxy_pass；不要直接套用 deploy/nginx.conf 模板，也不要假定 /var/www/english-garden 是当前网站目录。

控制台已核对：广州轻量服务器，实例 lhins-eh9t1bhd，公网 IP 134.175.134.240。可以通过腾讯云 OrcaTerm 的免密连接（TAT）以 ubuntu 用户登录。服务器运行 Ubuntu/Nginx，实例显示名称为“宝塔Windows面板-KcTP”。部署过程中不要修改登录凭据或其他网站。

1. 本机运行 npm run build，或使用最新 release-website.zip。压缩包根目录应含 index.html、match-effects.css、vocabulary-data.js、curriculum-plan.js、word-curriculum.js、sw.js 和 assets/。
2. 确认实际网站目录，将旧站点完整备份到网站目录之外，记录恢复方法。检查上传包是否完整后再替换，优先使用临时目录和原子切换。
3. 若现有配置无需变更，静态文件更新不需要重启服务器。若确实需要改 Nginx 配置，先通过 nginx -t 再 reload。
4. 从公网核对首页和关键 JS/CSS/图片返回成功，确认包含 match-effects.css 和 readPart 语音衔接逻辑，并与本机构建文件的 SHA256 比较。
5. 用手机尺寸检查四级/六级入口、消除、花瓣爆开、连消提示、进度奖励与花束收藏。中英文语音需要真实设备试听。
6. 回报部署时间、备份位置、上线文件校验结果和仍需核对的事项。如检查失败，恢复备份。

本地检查命令：node checks/word-garden.cjs word-garden-premium.html、node checks/vocabulary-ui.cjs、node checks/match-effects.cjs、node checks/preview-premium.cjs。后三项中的前两项需要 npm run serve 启动 http://127.0.0.1:4173/。
